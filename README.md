# ☕ Coffee Delivery

O **Coffee Delivery** é uma aplicação web de cafeteria desenvolvida com o objetivo de colocar em prática conceitos fundamentais do ecossistema **React**, explorando a construção de interfaces responsivas, gerenciamento de pedidos, validação de dados e aplicação de boas práticas de desenvolvimento.

O projeto simula uma experiência simples de compra de cafés, permitindo ao usuário selecionar produtos, definir quantidades, acompanhar os valores dos pedidos e finalizar sua compra por meio de uma interface intuitiva e responsiva.

Durante o desenvolvimento, foram aplicados conceitos de **React**, **Styled Components** e **Zod**, além de princípios de **Clean Code**, organização de componentes e validação de informações. A aplicação também busca manter uma estrutura escalável e de fácil manutenção, utilizando boas práticas para tornar o código mais consistente e compreensível.

Mais do que uma aplicação de cafeteria, o Coffee Delivery foi desenvolvido como um projeto prático de evolução técnica, permitindo exercitar conceitos importantes do desenvolvimento front-end moderno e consolidar conhecimentos necessários para a construção de aplicações web mais completas, organizadas e funcionais.
